# Монополия

Третья игра семейства. Классические правила целиком плюс режим большого
развития. До шести игроков, каждый со своего телефона по Wi-Fi. Валюта — рубли.

## Режимы

| Режим | О чём он |
| --- | --- |
| 🎩 Классика | Полные правила: торги за отказ, залог, равномерная застройка, 32 дома и 12 отелей в банке, игра до последнего |
| ⚡ Блиц | Старт 3 млн ₽, без торгов, пятнадцать кругов |
| 🏡 Семейная | Куш на стоянке, двойная выплата за точный «Старт», без залогов, двенадцать кругов |
| 🏙️ Магнат | Небоскрёбы поверх отелей, банковские кредиты, скромный старт |
| ⏱️ Спринт | Ровно восемь кругов, побеждает капитал |

## Что реализовано из классики

Все сорок клеток в канонической расстановке, восемь цветных групп, четыре
вокзала и две коммунальные службы. Броски двумя кубиками с дублями и тюрьмой
за три дубля подряд. Покупка или аукцион при отказе. Аренда с удвоением за
собранную группу, аренда вокзалов по их числу и коммунальных служб по броску.
Равномерная застройка домами и отелями с ограниченным запасом в банке. Залог
и выкуп с десятью процентами. Тюрьма с залогом, карточкой и дублем. Обе колоды
по шестнадцать карточек. Обмен участками, деньгами и карточками между игроками.
Банкротство с передачей имущества кредитору.

## Деньги

Номиналы взяты из классической игры и умножены на тысячу, чтобы суммы звучали
по-настоящему: старт 1,5 млн ₽, самая дешёвая улица 60 000 ₽, Красная площадь
400 000 ₽. Крупные суммы показываются сокращённо — «1,5 млн ₽».

## Игра по сети

Один телефон становится столом: внутри приложения поднимается WebSocket-сервер,
а UDP-маячок рассказывает о комнате соседям — вводить IP-адреса не нужно.

В отличие от «Морского боя», здесь по сети рассылается полное состояние партии:
доска, деньги и имущество в Монополии открыты всем по правилам, скрывать нечего.
Хост остаётся единственным судьёй — любое действие гостя проходит через тот же
движок, что и на его собственном устройстве.

## Боты

- 🙂 **Новичок** — покупает через раз, строит редко.
- 💼 **Делец** — считает наличные, собирает группы, строит вовремя.
- 🎩 **Магнат** — держит запас, охотится за оранжевыми и красными улицами,
  торгуется на аукционах и предлагает выкупить участок, замыкающий его группу.

## Разработка

```bash
npm install
npm run dev          # веб-версия на http://localhost:5175
npm run lan          # вспомогательный сервер комнат для браузера (порт 8789)
npm run build
npx cap sync android
```
