# Дилемма заключённого

Игра о доверии, жадности и репутации для компании от 2 до 16 человек — на одном
телефоне или по Wi-Fi, каждый со своего устройства. Android APK собирается в
GitHub Actions, локально ничего ставить не нужно.

## Игры в этом репозитории

| Игра | Папка | Тег релиза |
| --- | --- | --- |
| 🤝 Дилемма заключённого | корень репозитория | `v*` |
| ⚓ Морской бой | [`seabattle/`](seabattle/) | `sea-v*` |
| 🎩 Монополия | [`monopoly/`](monopoly/) | `mono-v*` |

Игры ставятся независимо друг от друга. Внутри каждой есть экран
«Наши игры»: он проверяет, что уже установлено на телефоне, и предлагает
скачать недостающее.

Сетевая часть у всех трёх общая: один телефон поднимает у себя комнату
(WebSocket-сервер плюс UDP-маячок, адреса вводить не нужно), остальные
подключаются к нему. У клиента есть постоянная метка устройства, поэтому
после погасшего экрана или моргнувшего Wi-Fi он возвращается на своё место
в той же партии, а не выпадает из неё.

## Что внутри

**7 режимов**, которые сами подстраиваются под число участников:

| Режим | Игроков | Суть |
| --- | --- | --- |
| 🎭 Дуэль | 2 | Классическая повторяющаяся дилемма один на один |
| ⚔️ Арена | 3–12 | Каждый раунд новая пара, репутация ходит за вами |
| 🏛️ Турнир | 3–12 | Один ход применяется сразу ко всем соперникам |
| 🌍 Общее дело | 3–16 | Игра общественных благ: общий котёл делится на всех |
| 🌀 Хаос | 3–12 | Турнир со случайными событиями и туманом недопонимания |
| 🏡 Семейный | 2–10 | Мягкие формулировки и щедрая матрица — для детей |
| 🤖 Против ботов | 1–8 | Вы против классических стратегий |

**Фичи**

- 12 ботов с настоящими стратегиями из турниров Аксельрода: Зеркало, Злопамятный,
  Павлов, Детектив, Провокатор, Акула и другие.
- Контекстные подсказки: игра замечает, что вы предали трижды подряд, что идёт
  последний раунд или что котёл рушится, и говорит об этом.
- Случайные события: удвоение ставок, амнистия, налог на подлость, затемнение.
- «Туман недопонимания» — ход с некоторой вероятностью искажается в противоположный.
- Неизвестный финал партии — лечит эффект последнего хода.
- 5 матриц выплат от «Доверия» до «Жестокого мира».
- Разбор в конце: на какую классическую стратегию вы оказались похожи, график
  очков по раундам, 10 достижений.
- Академия — теория игр за полторы минуты.
- Анимации, тактильный отклик и звук, синтезированный на лету (ни одного
  медиафайла в APK).

## Как играть

**На одном телефоне.** «Играть» → режим → список игроков → старт. Между ходами
появляется ширма «передайте телефон», чтобы выбор оставался тайным.

**По Wi-Fi.** Один игрок открывает комнату — его телефон становится сервером.
Остальные выбирают «По Wi-Fi → Подключиться» и видят комнату в списке
автоматически: интернет не нужен, достаточно общей сети. Если сеть блокирует
широковещательные пакеты, адрес можно ввести руками.

## Сборка APK через GitHub Actions

1. Создайте пустой репозиторий на GitHub.
2. Из папки проекта:

```bash
git init && git add . && git commit -m "Дилемма заключённого" && git branch -M main && git remote add origin https://github.com/ВАШ_ЛОГИН/ВАШ_РЕПОЗИТОРИЙ.git && git push -u origin main
```

3. Откройте вкладку **Actions** — сборка «Сборка APK» запустится сама. Через
   5–8 минут в разделе **Artifacts** появится файл `dilemma-1.0.N.apk`.
4. Чтобы получить постоянную ссылку на скачивание, поставьте тег — тогда APK
   попадёт в **Releases**:

```bash
git tag v1.0.0 && git push origin v1.0.0
```

APK по умолчанию подписывается отладочным ключом — он устанавливается на любой
телефон, но у каждой машины ключ свой. Чтобы обновления ставились поверх, заведите
постоянный ключ и положите его в секреты репозитория:

```bash
keytool -genkey -v -keystore release.jks -keyalg RSA -keysize 2048 -validity 10000 -alias dilemma
base64 -w0 release.jks > release.txt
```

Затем **Settings → Secrets and variables → Actions** и добавьте:
`ANDROID_KEYSTORE_BASE64` (содержимое `release.txt`), `ANDROID_KEYSTORE_PASSWORD`,
`ANDROID_KEY_ALIAS` (`dilemma`), `ANDROID_KEY_PASSWORD`.

### Установка на телефон

Скачайте APK, откройте его — Android попросит разрешить установку из неизвестных
источников. Минимальная версия — Android 6.0.

## Разработка

```bash
npm install
npm run dev
```

Откроется на `http://localhost:5173`, а также по адресу вашего компьютера в
локальной сети — можно открыть с телефона и играть без сборки APK.

Чтобы проверить сетевой режим прямо в браузере, нужен вспомогательный
ретранслятор (в APK он не участвует — там комнату держит сам телефон):

```bash
npm run lan
```

### Локальная сборка APK

Нужны JDK 17+ и Android SDK. Затем:

```bash
npm run sync && cd android && ./gradlew assembleRelease
```

Готовый файл — `android/app/build/outputs/apk/release/`.

## Устройство проекта

```
src/game/       правила: матрицы, движок раундов, стратегии ботов, события,
                подсказки, достижения — чистые функции без React
src/store/      состояние приложения (zustand + сохранение настроек)
src/net/        протокол комнаты, хост, клиент, поиск комнат в сети
src/ui/         экраны и компоненты
android/…/LanPlugin.java   WebSocket-сервер и UDP-маячок прямо на телефоне
server/lan-server.mjs      ретранслятор для отладки в браузере
```

Хост — источник истины: он считает раунд и рассылает всем полный снимок
состояния, клиенты отправляют только свой ход. Партия детерминирована по seed,
поэтому расхождений между устройствами не бывает.

## Приватность

Игра не собирает и никуда не отправляет данные. Сетевой режим работает
исключительно внутри вашей локальной сети.
