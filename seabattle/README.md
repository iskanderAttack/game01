# Морской бой

Вторая игра семейства. От классических правил из тетрадки в клетку до
штабной стратегии с радарами, торпедами и минами. От одного игрока
против ботов до восьми человек по Wi-Fi.

## Режимы

| Режим | Игроков | О чём он |
| --- | --- | --- |
| ⚓ Классика | 2 | Канонические правила: 10×10, попал — стреляй ещё |
| ⚡ Блиц | 2–4 | Таймер 12 секунд на залп, без дополнительного хода |
| 👑 Королевская битва | 3–8 | У каждого своё поле, цель выбираете сами, выбывание |
| 🎌 Эскадры | 4–8 | Две команды, карты союзников открыты |
| 🎖️ Адмирал | 2–6 | Энергия и восемь способностей |
| 🏡 Семейный | 2–6 | Поле 7×7, подсказки «горячо — холодно» |
| 🎯 Охота | 1 | Потопить флот за минимум выстрелов, рекорд сохраняется |

## Способности режима «Адмирал»

Энергия копится за попадания: +1 за палубу, +3 за потопленный корабль.
Обычный выстрел бесплатен всегда.

🛠️ Ремонт · 🌫️ Дымзавеса · ⚓ Мина

## Боты

- 🧢 **Юнга** — стреляет почти наугад.
- 🎣 **Боцман** — шахматный поиск плюс уверенное добивание вдоль линии.
- 🎖️ **Адмирал** — строит карту вероятностей по всем возможным расстановкам
  оставшегося флота. Играет сильнее большинства людей.

Боты рассуждают только о том, что видно любому сопернику: сетка выстрелов,
объявленные потопления и состав флота. В чужую расстановку они не заглядывают
даже технически.

## Игра по сети

Один телефон становится комнатой: внутри приложения поднимается
WebSocket-сервер, а UDP-маячок рассказывает о комнате соседям — вводить
IP-адреса не нужно. Игры используют разные порты, поэтому комнаты
«Морского боя» и «Дилеммы» не путаются в эфире.

**Важно:** общее состояние партии по сети не рассылается. В нём лежат
расстановки всех флотов, и любой желающий прочитал бы их прямо из трафика.
Хост собирает каждому игроку персональный вид: своё поле целиком, чужие —
только как набор известных фактов (выстрелы, объявленные потопления и
собственная разведка). Расстановку, присланную клиентом, хост проверяет
по правилам поля, а не принимает на слово.

## Разработка

```bash
npm install
npm run dev          # веб-версия на http://localhost:5174
npm run lan          # вспомогательный сервер комнат для браузера (порт 8788)
npm run build        # сборка
npx cap sync android # перенести сборку в Android-проект
```

Для игры по сети из браузера нужен `npm run lan` на компьютере: в браузере
приложение не может поднять сервер само. В APK всё работает без него.

## Сборка APK

APK собирается в GitHub Actions. Тег `sea-v1.0.0` публикует релиз со
сборкой на [странице релизов](https://github.com/iskanderAttack/game01/releases).

```bash
git tag sea-v1.0.0
git push origin sea-v1.0.0
```

Отметку «latest» на странице релизов держит «Дилемма заключённого» —
на неё ведёт напечатанный QR-код, поэтому релизы «Морского боя»
публикуются без этой отметки.
